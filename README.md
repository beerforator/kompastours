# Компас — концепция главной страницы

Локальный статичный React + Vite макет. Без сервера приложений, оплаты, реального поиска и отправки заявок.

## Запуск

```sh
npm install
npm run dev
```

Сборка: `npm run build`. Для статического хостинга используется папка `dist`.

Исходные фотографии и логотипы сохранены с kompastours.ru. Список источников: `public/images/sources.json`. Основные тексты перенесены с сайта; короткие редакционные заголовки добавлены для концепции. Даты в поиске — демонстрационные значения исходного интерфейса, не предложение к бронированию. Внешние информационные ссылки ведут на действующий сайт. Шрифт Manrope загружается через Google Fonts с системным запасным вариантом.

Проверка: production-сборка, широкая и мобильная композиции, переключение поиска, отсутствие горизонтального переполнения. Исходные обещания 24/7 и ответа за 15 минут сохранены и требуют подтверждения владельцем перед публикацией.
